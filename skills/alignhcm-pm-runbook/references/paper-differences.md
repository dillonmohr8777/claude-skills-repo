# UKG paper and Align paper

Whose contract the project runs on changes access, sign-offs, escalation, and
governance. Confirm which one applies before the first readiness session.
Getting it wrong costs the first two weeks.

## Access provisioning

| | UKG paper | Align paper |
|---|---|---|
| Who grants access | UKG, based on the SOW | The client |
| How | PM confirms every team member received credentials and can reach the client environment | PM initiates the request with the customer; client submits cases in the UKG community |
| Backup resources | Must also confirm access at project start. If none are identified, PM works with the practice lead | Same, using the email template and partner access request |
| If credentials are missing | Submit the partner access issues form | Raised through the client's case |
| Integration dashboard | Consultants request access via the partner access issue form | Same route |
| Training monitoring | PM submits a partner access issue form to add the client to University | Not applicable in the same form |

## Project readiness

- **UKG paper**: UKG has folded project readiness into the project kickoff deck.
- **Align paper**: Align runs targeted readiness sessions covering preparation
  for analysis and kickoff, training, change management and testing, and data
  conversions and integrations.

## Kickoff deck

UKG paper uses the UKG-branded deck plus additional slides for client
responsibilities and sign-off requirements. Align paper uses the Align-branded
deck.

## Escalation

**Internal, both papers:** PM first, then practice lead, then COO.

**External on UKG paper:** PM reaches out to the PDAM, escalates to the practice
lead, who engages the partner alliance manager.
